## Fix de Mayor Impacto (2 líneas)

```ts
// lib/language-context.tsx

// Línea 32 — default del useState:
const [language, setLanguageState] = useState<Language>('de'); // era 'es'

// Línea 66 — fallback de detectBrowserLanguage():
return 'de'; // era 'es' — Default to German for DACH market
```

Este cambio elimina el SSR flash en español para TODOS los usuarios alemanes.
